# Data

`HR-Employee-Attrition.csv` is the IBM HR Analytics Employee Attrition sample dataset, a publicly available file that is widely used for teaching. It is a fictional dataset created by IBM data scientists, so the results in this repo say something about the method, not about any real company.

- 1,470 employees, 35 columns
- Target: `Attrition` (Yes / No), about 16% of employees are "Yes"
- Four columns are dropped before modelling because they hold a single value or are just an ID: `EmployeeCount`, `Over18`, `StandardHours`, `EmployeeNumber`
